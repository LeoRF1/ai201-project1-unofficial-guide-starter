Description:

An advanced 3-credit computer science course focused on web application development.
The course equips students with the modern tools and concepts required to build robust, scalable, and dynamic web applications.
The course covers a comprehensive blend of frontend and backend web technologies. Core topics generally include , Client-Side Technologies, 
server side development, database integration.


Professor: Dr. kafi Rahman.
